Glossary:
- order_facts has one row per order; review_facts has one row per review and all the order columns, so no joins are needed.
- Customers are people: count them with COUNT(DISTINCT customer_unique_id). Never count orders as customers.
- is_late is true when an order arrived after its estimated delivery date; it is NULL when the order was not delivered.
- The days_* columns are whole days. Use them for durations instead of date arithmetic.
- purchase_month looks like '2018-03'; group and filter months with it.
- customer_order_number is the n-th order of a customer; above 1 means a returning customer.
- State codes are uppercase, like 'SP'. City names are lowercase without accents, like 'sao paulo'.
- Give shares, rates and percentages as percentages from 0 to 100.
- A question for a single number returns just that number. A question about which items rank highest or lowest returns each item with its number: 'the most' returns one row, 'the top N' returns N rows.

Examples:
Question: What share of customers in Rio Grande do Sul ordered more than once?
```sql
SELECT round(100 * avg(CASE WHEN orders > 1 THEN 1 ELSE 0 END), 2) AS pct_repeat_customers
FROM (SELECT customer_unique_id, count(*) AS orders FROM order_facts WHERE customer_state = 'RS' GROUP BY customer_unique_id)
```

Question: GO late rate
```sql
SELECT round(100 * avg(is_late::INT), 2) AS pct_late
FROM order_facts WHERE customer_state = 'GO'
```

Question: List the 10 states where deliveries take the longest on average.
```sql
SELECT customer_state AS state, round(avg(days_to_deliver), 1) AS avg_delivery_days
FROM order_facts WHERE order_status = 'delivered'
GROUP BY customer_state ORDER BY avg_delivery_days DESC, state LIMIT 10
```

Question: On which day in April 2017 were the most orders placed?
```sql
SELECT purchase_date AS day, count(*) AS orders
FROM order_facts WHERE purchase_month = '2017-04'
GROUP BY purchase_date ORDER BY orders DESC, day LIMIT 1
```

Question: How many orders came from customers in Niterói?
```sql
SELECT count(*) AS orders FROM order_facts WHERE customer_city = 'niteroi'
```

Question: How many 2-star reviews include a written comment?
```sql
SELECT count(*) AS reviews FROM review_facts WHERE review_score = 2 AND has_comment
```
